# 登录页视觉改版记录

- 范围：仅登录页 `/login`（正常登录卡片与首次使用设置卡片）；其他页面不动。
- 主责：member/a 吴妍萱（前端、原型与页面交互）。
- 依据：用户 2026-11-27 提供的三张参考图（ENJOY/小熊海报、居中双栏卡片登录稿、阅览室照片）与文字要求——背景用第三张图 50% 透明；卡片整体自右下向左上渐浅；中间分界不要明显；保留 ENJOY! 下方两行英文；logo 沿用现有站标、名称改黑色。
- 无正式需求编号，不涉及 FR/BR/AC、业务规则、接口与权限变更；纯展示改版。

## 实现

- `frontend/src/views/LoginView.vue`：页面改为「照片背景 + 居中双栏卡片」。
  - 背景层 `.auth-photo` 使用新增 `public/images/login-bg.jpg`，`opacity: .5`，3px 模糊；基础底色为米白 `#f2efe6`。
  - 卡片背景 `linear-gradient(to top left, #dcd4c5, #efece4 52%, #f8f6f0)`：右下深、左上浅；两栏之间仅 `rgba(92, 80, 56, .06)` 的 1px 细线。
  - 左栏使用新增 `public/images/login-bear.png`：由用户提供的海报图去除浅灰背景得到，保留 ENJOY!、两行英文与 READ!，以及小熊下方投影。
  - 右栏表单：欢迎回来、账号/密码、绿色登录按钮（设计稿取色 `#52966d`）与两条说明文案；首次使用设置沿用同一卡片改为单列布局。
  - 左上角品牌沿用现有书本站标（`#2f5d46` 底 + 白色图标），「静阅自习室」「QUIET READING STUDY ROOM」改为黑色。
  - 登录页固定浅色外观：在 `.auth-shell` 上覆盖一套浅色主题令牌，避免深色主题下输入框/按钮与米白卡片冲突。
- 原左侧品牌文案、四项功能卡与阅读插画随版式移除；`public/images/login-reader.png` 不再被引用（保留在仓库，未删除）。

## 验证

- `npm run build` 通过；前端测试 322 条、321 通过（唯一失败为既有首页用例）。
- 本地 5174 实际页面（登录页无需登录）在 1440×900 与 560×860 截图核对：照片背景 50%、卡片渐变与淡分界线、小熊与两行英文、黑色 logo、表单与按钮符合参考稿；窄屏隐藏插画、单列卡片正常。
- 未验证：真实账号登录后的跳转（登录与首次设置逻辑未改，沿用原实现）、本机 Chromium 以外的浏览器、深色主题观感（页面已固定浅色）。
