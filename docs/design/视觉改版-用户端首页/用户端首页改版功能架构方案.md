# 用户端首页改版功能架构方案

视觉改版-用户端首页 / 前端（member/a，吴妍萱）。范围：仅学生/教职工（普通用户）首页改版；管理员端首页保持首页 hero 改版状态不变，其他页面全部不动。纯展示改版，无业务规则、FR/BR/AC 变更；统计口径沿用原「我的概览」卡片（pending/checked_in/completed/累计，取本人预约第 1 页 20 条）。

## 需求依据（用户 2026-11-26 提供 8 张设计图与文字要求）

1. 首页上半部分按第 1 张图；图中的要求为「我的概览不再单独出现」，四个个人指标并入顶部区。
2. 「常用功能」换成「自习室种类」卡片（样式参照第 4 张图），A/B/C/D 四区卡片背景分别嵌入第 5/6/7/8 张图。
3. 保留使用须知与我的学习安排。
4. 页面背景换成第 3 张图的颜色。
5. 第 2 张图经核为现「我的概览」卡片截图（即要求移除的参照），不单独实现。

## 结构（普通用户分支，HomeView 按 auth.isAdmin 分流）

`取消通知条（原功能保留）→ 顶部大图+统计条 → 自习室列表（4 卡）→ 使用须知 + 我的学习安排`。管理员分支完整保留首页 hero 改版布局（hero/home-hero.jpg、常用功能、今日概览、管理提示、学习安排）。

## 验收例

1. `npm run build` 通过；前端 node 测试不新增失败（既有 roles.test.js:115 失败与此无关）。
2. 普通用户实测：底色 rgb(224,240,240)；顶部图加载；统计条显示真实值（实测 0/0/9/11）；4 张区卡图全部加载；使用须知与学习安排存在；「我的概览」、旧 hero、常用功能均不出现。
3. 管理员实测：home-top/home-stats/zone-card 均不存在，hero/home-hero.jpg、常用功能、今日概览、问候头全部保持。
4. 多视口：1280/934 实测通过；卡片栅格 1200px 断点 4→2 列、760px 断点 2→1 列。

- 卡片文案为静态展示（对应种子数据默认值），不调 getRooms/getOpeningWindows，避免新增请求与失败态；如需接真实房间数据可后续扩展。
