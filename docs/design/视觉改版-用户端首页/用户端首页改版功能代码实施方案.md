## 实际改动

1. `frontend/src/views/HomeView.vue`：
   - 根节点按角色加 `home-page--user` 类（普通用户才应用冰蓝底色）。
   - 模板拆为两分支：`v-if="auth.isAdmin"` 保留原布局（首页 hero 改版、常用功能、今日概览、管理提示、学习安排，仅把原来按角色三元判断的文案固化为管理员版）；`v-else` 为普通用户新版首页：取消通知条、顶部大图+统计条、自习室列表 4 卡、使用须知、我的学习安排。

2. 新增素材（`frontend/public/images/`）：
   - `home-top.jpg`（1636×720，190KB）：图 1 顶部裁剪（y 0–720，避开烘焙统计数字区）。
   - `zone-a.jpg`/`zone-b.jpg`/`zone-c.jpg`/`zone-d.jpg`（880×495，各约 90KB）：第 5–8 张图缩放。

### 2026-11-27 hero 底部颜色过渡，上下衔接自然

用户反馈：上半部分（hero 深色照片）与下半部分（冰蓝底色内容区）之间存在生硬分界，要求把上半部分的颜色过渡下来、衔接自然。用户附 4 张图，其中 2 张可解析（2880×894 的 hero 局部与 2880×1414 的全页截图）；经像素采样确认分界位置：深色 hero 在页面约 60% 高度处直接跳变为 `#e0f0f0`。

处理：

1. `.hero-full::after` 新增底部渐隐层：`position: absolute; bottom: 0; height: clamp(72px, 13vh, 140px)`，背景 `linear-gradient(to bottom, transparent, #e0f0f0)`——照片最后一段连续过渡到与页面底色完全一致的 `#e0f0f0`，与 hero 之下的 26px 间距和下方内容区无缝衔接；`pointer-events: none` 不拦截交互，绘制在 `.hero-inner`/`.hero-bottom`（z-index:1）之下，不影响文案、按钮与统计卡。
2. `.hero-kpi` 增加 `text-shadow: 0 1px 10px rgba(8, 16, 22, .4)`：渐隐区背景变浅后，玻璃统计卡上的白字数字仍保持可读（统计卡位于渐隐带上缘）。
3. 管理员端 hero（`.hero`，卡片式布局）未加渐隐，保持首页 hero 与本次改版的既有观感。

实测（1280×720，学生账号，浏览器 DOM + 截图像素采样）：`.hero-full::after` 计算样式 bottom=0、height≈93.6px（13vh）、background 为 transparent→rgb(224,240,240)；hero 底边 y=544。截图逐行采样（x=100/400/700/1000/1180，y=420→560）：照片深色（如 x=400 的 #2b3c45）经 #415159→#67777c→#9dabad→#c5d5d7 连续过渡到 y=540 的 #d8e8e8，y=550 起稳定为 #e0f0f0 与页面底色一致，无跳变。`npm run build` 通过；node 测试 306/307（既有失败，与本改无关）。最终观感由用户肉眼确认，渐变高度可原位微调（改 `clamp` 或固定高度）。
