## 本人记录与消息提示

依据用户对前端提示的反馈，消息中心直接显示已读结果。写入返回失败时可点击「检查已读状态」，从消息列表和未读数读取当前结果。同一条历史消息是否提供详情入口，继续按真实关联判断。

个人中心先展示能否预约、去预约入口和当前限制，限制记录可按需筛选。违规和信誉分记录用简短的字段名，并在未加载成功时提供对应查询入口。

验收覆盖消息请求结果不确定时读取最终状态、消息与本人记录的真实关联、限制资格读取失败时的展示，以及违规记录的第三方信息边界。

### 2026-11-27 消息中心切换分类校正右侧详情
