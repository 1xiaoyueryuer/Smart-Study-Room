# 首页 Hero 区视觉改版功能架构方案

F13 / 前端（member/a，吴妍萱）。范围：仅首页顶部 hero 区视觉改版，按用户 2026-11-26 提供的设计稿实施；常用功能、我的概览、学习安排、小贴士等其余区块与全部业务行为保持不变。纯视觉改动，不涉及需求修订、无 FR/BR/AC 变更，角色权限与文案形态沿用现状（学生/教职工见「今日宜专注/立即预约」，管理员见「今日运营，一目了然/查看统计」）。

## 设计规格（自用户设计稿实测提取）

用户提供的设计稿为 3872×1120 位图（按 2x 还原）。本模型无图像输入能力，规格通过 Windows OCR（zh-Hans-CN）与 PIL 像素采样提取，并经用户确认「只改 hero 区、素材从设计稿裁剪」：

| 元素 | 实测值（设计稿） | 落地实现 |
|---|---|---|
| 背景 | 奶油底，左上亮、右侧渐暗：#FAF4E4 → #F0E9D6 | `linear-gradient(100deg, #fbf5e5, #f7f0de 52%, #efe7d4)` + 左上柔光 radial |
| 眉题「静阅 · 专注空间」 | 原稿几乎与背景同色（lum≈240 vs 背景 243） | #d9cba4，保留弱化质感但保证可读 |
| 主标题 | 深绿 #14291F，尺寸约占 hero 高 20% | color #14291f，字号 clamp(38px,4.2vw,60px) 不变 |
| 副标题 | 深绿 #13271B | #1f3a2b |
| CTA 按钮 | 深绿圆角胶囊 #204637，白字 #FFFFFF，圆角约 20px@1x | SButton primary + 覆盖：背景 #204637、白字、border-radius 999px、高 52px、宽 padding 30px |
| 右侧大图 | 深暖色调场景图，左缘不规则并带柔和投影，占画面约右 38–50% | 自设计稿裁剪 x1950..3872 全高 → `public/images/home-hero.jpg`（1440×839，约 225KB，JPEG q90） |
| 左下绿色块 | 经放大解析为 CTA 胶囊按钮本体（白色「立即预约」在深绿底上），非植物照片 | 由 CTA 按钮承担 |

## 交互与结构

- hero 容器：圆角 r-2xl、overflow hidden、min-height 320px；文字列占网格 54%（`minmax(0,1fr) 46%`），照片绝对定位于右、高 100%、宽 46%、`object-fit: cover; object-position: right center`——裁掉素材左侧冗余空白/投影区，保证文字列与照片深色内容不相交。
- 照片为纯装饰（`alt=""` + `aria-hidden="true"`），不参与语义与交互；点击行为仍在 CTA 按钮。
- 响应式：>760px 显示照片；≤760px 隐藏照片、hero 单列、min-height 300px，与原设计一致。
- 深色主题下 hero 维持奶油底（与旧版 hero 固定浅色底的行为一致），照片素材不受主题切换影响。

## 验收例

1. `npm run build` 通过，无新增告警（既有 SeatScene/Analytics chunk 提示与本次无关）。
2. 浏览器实测 1440×900 / 934×708 / 400×800 三档视口：照片贴右缘、文字与照片无重叠（DOM 实测文字右缘 < 照片左缘）、400px 下照片 display:none、按钮背景 rgb(32,70,55)、圆角 999px、白字。
3. 图片资源加载成功（naturalWidth=1440）。
4. 前端 node 测试不因本次改动新增失败。
5. 学生与管理两种 hero 文案形态均正常渲染（复用原有模板分支，未改文案逻辑）。

## 风险与未验证项

- 本模型无法直接查看设计稿图片，右侧大图内容、边缘形状均按像素分析推断；如实际效果与用户预期有出入，素材与尺寸参数可原位微调（图片替换只需覆盖 `home-hero.jpg`）。
- 未做人工视觉走查与截图目检；DOM 几何测量代替。
