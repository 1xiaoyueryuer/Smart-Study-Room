# 用户端首页改版功能代码实施方案

F14。范围、设计规格与验收例见同目录架构方案；本文件记录实际实现与验证结果。

## 实际改动

1. `frontend/src/views/HomeView.vue`：
   - 根节点按角色加 `home-page--user` 类（普通用户才应用冰蓝底色）。
   - 模板拆为两分支：`v-if="auth.isAdmin"` 保留原布局（F13 hero、常用功能、今日概览、管理提示、学习安排，仅把原来按角色三元判断的文案固化为管理员版）；`v-else` 为普通用户新版首页：取消通知条、顶部大图+统计条、自习室列表 4 卡、使用须知、我的学习安排。
   - 新增 `zones` 静态数组（1F-A/B/C/D 区卡片文案与图片路径）；统计条沿用既有 pendingCount/checkedInCount/completedCount/totalCount 计算值，未新增任何 API 调用。
   - 新增样式：`.home-page--user`（#e0f0f0 + 100vmax box-shadow 全幅铺底）、`.home-top`（圆角容器 + #476467）、`.home-top-img`（aspect-ratio 1636/720 + 底部 7% 渐变蒙版衔接统计条）、`.home-stats*`、`.zone-*`（4 列栅格，1200px→2 列、760px→1 列）。
2. 新增素材（`frontend/public/images/`）：
   - `home-top.jpg`（1636×720，190KB）：图 1 顶部裁剪（y 0–720，避开烘焙统计数字区）。
   - `zone-a.jpg`/`zone-b.jpg`/`zone-c.jpg`/`zone-d.jpg`（880×495，各约 90KB）：第 5–8 张图缩放。

## 实际验证

- 生产构建：`npm run build` 通过（2.5s）。
- 前端 node 测试：307 条 306 过，唯一失败仍为既有 `roles.test.js:115`（期望 HomeView 导出 loadRooms，与本次无关，script 未新增 API）。
- 浏览器实测（dev 5174，真实登录）：
  - 普通用户（模拟学生1，934/1280 两档视口）：页面底色 rgb(224,240,240)；home-top 图与 4 张区卡图全部加载；统计条真实值 0 待签到 / 0 使用中 / 9 已结束 / 11 累计预约；使用须知与我的学习安排存在；「我的概览」、旧 hero、常用功能、问候头均不再出现。
  - 管理员（202630001，1280）：home-top/home-stats/zone-card 均为 0 个；hero 图 home-hero.jpg 正常加载、「今日运营，一目了然」、常用功能（热力图统计/管理端/个人中心）、今日概览、学习安排全部保持；页面无冰蓝底色。
  - 验证后已恢复学生账号登录与 934 视口。
- F13 方案文档补充说明：F13 hero 视觉自 F14 起仅应用于管理员端首页。
