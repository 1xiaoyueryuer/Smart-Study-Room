# 用户端首页改版功能代码实施方案

F14。范围、设计规格与验收例见同目录架构方案；本文件记录实际实现与验证结果。

## 实际改动

1. `frontend/src/views/HomeView.vue`：
   - 根节点按角色加 `home-page--user` 类（普通用户才应用冰蓝底色）。
   - 模板拆为两分支：`v-if="auth.isAdmin"` 保留原布局（F13 hero、常用功能、今日概览、管理提示、学习安排，仅把原来按角色三元判断的文案固化为管理员版）；`v-else` 为普通用户新版首页：取消通知条、顶部大图+统计条、自习室列表 4 卡、使用须知、我的学习安排。
   - 新增 `zones` 静态数组（1F-A/B/C/D 区卡片文案与图片路径）；统计条沿用既有 pendingCount/checkedInCount/completedCount/totalCount 计算值，未新增任何 API 调用。
   - 新增样式：`.home-page--user`（#e0f0f0 + 100vmax box-shadow 全幅铺底）、`.home-top`（圆角容器 + #476467）、`.home-top-img`（aspect-ratio 1636/720 + 底部 7% 渐变蒙版衔接统计条）、`.home-stats*`、`.zone-*`（4 列栅格，1200px→2 列、760px→1 列）。
2. 新增素材（`frontend/public/images/`）：
   - `home-top.jpg`（1636×720，190KB）：图 1 顶部裁剪（y 0–720，避开烘焙统计数字区）。
   - `zone-a.jpg`/`zone-b.jpg`/`zone-c.jpg`/`zone-d.jpg`（880×495，各约 90KB）：第 5–8 张图缩放。

## 迭代记录

### 2026-11-26 hero 改全幅铺满 + 悬挂小黑板

用户第三次反馈：以原图为准，副标题改为「预约属于你的专属座位，找到一段不被打扰的学习时光」；顶部不再做成卡片，改为铺满上半屏；右上角悬挂长方形小黑板，内容为「我的学习安排」。

原图（1608×974）中的文字、按钮与统计数字均为烘焙内容，因此先做图像处理再用 HTML 重构：

1. 图像处理（Python + OpenCV）：裁掉 y≥690 的烘焙按钮/统计/信息行；对眉题、两行大标题、两行副标题区域用「白顶帽检测亮细笔画 + 形态学膨胀 + Telea inpaint」清除文字。首轮中值背景检测因笔画密集漏检（标题仍残留笔画），改用 21px 椭圆核白顶帽并叠加金色（R-B>45）判据后清除干净；核对蒙版形状贴合笔画、未误伤窗户竖框，吊灯等真实亮点保留。
2. `frontend/public/images/home-top.jpg` 重新生成为 1608×690（99KB，去文字去UI）。
3. 模板：`.hero-zone` + `.hero-full` 全幅 hero（`margin: -28px calc(50% - 50vw) 0` 冲出版心到视口边缘，`min-height: clamp(460px, 58vh, 760px)`，背景图 cover，左侧 95° 压暗渐变保证可读）；HTML 渲染眉题（带短横线）、两行标题（「算数」金色 #dcbd7a）、新副标题、立即预约/我的预约按钮、开放时间信息行、右下角四个玻璃统计卡（真实数据）；右上角 `.board` 悬挂小黑板（木质边框渐变 + 深绿板面 + 两根吊绳 + -1.4° 倾斜），内容为我的学习安排：待签到项直连扫码页，其余跳 /mine，空态给「去选座」。
4. 下方原「我的学习安排」卡片移除（已并入小黑板），保留自习室列表与使用须知。
5. 响应式：≤1200px 黑板改为静态右对齐（max-width 360px）、统计卡移入流内；≤760px hero 内边距与字号收缩。

实测（1280×860 / 934×800）：hero 宽度等于视口宽、高 553px（约 64% 视口）；背景图加载成功（1608×690）；小黑板 304×161 挂于右上、与标题和统计卡均无重叠；副标题文案与要求一致；页面底色 rgb(224,240,240)；旧 home-top 与我的学习安排卡片不再存在；区卡 4 张、使用须知保留。管理员分支未改动。构建通过，node 测试 306/307（既有失败）。

### 2026-11-26 标题/副标题/按钮行/黑板/区卡片五处修正

用户第四次反馈的五点，逐项处理：

1. 标题折行：`<br>` 改为两个 `.hero-title-line` 块级行，`white-space: nowrap`，字号自 clamp(38px,5.4vw,82px) 调为 clamp(28px,4.3vw,66px)，保证「今日宜专注」「让每一次坐下都算数」各自单行。实测 1600/1280/1200/934/480 五档均为单行（scrollWidth ≤ clientWidth，getClientRects 长度 1），且无横向滚动。
2. 副标题颜色不明显：根因是新 hero 与管理员 hero 共用 `.hero-sub`/`.hero-eyebrow` 类，管理员的 `color:#1f3a2b`（深绿）规则位于其后、同优先级覆盖了新规则的浅色。改为 `.hero-full .hero-sub` 提升优先级并显式 `#ffffff`（含 text-shadow），文案按要求为「预约属于你的专属座位，找到一段不被打扰的学习时光」。管理员 hero 的独立规则保持不变。
3. 按钮与统计同行：新增 `.hero-bottom` 行容器（左按钮组、右统计卡，`align-items:center` + `space-between`），移除按钮的原 margin-top 与「开放时间…」信息行（`.hero-meta` 已删除）。实测 1280 下按钮 y 439–497、统计卡 y 417–519，垂直中心对齐。
4. 黑板：宽度 300→384、top 0→30px、吊绳加长到 30px、板面增大（内边距 20/22、标题 19px、条目 14px 且允许换行 `overflow-wrap:anywhere`）、`min-height:196px`。按完整尺寸模拟 3 条最长预约：板高 318px、底边 426px 仍在 hero（底边 582px）内，无滚动溢出、无文字截断、底部余量 23px。
5. 区卡片：数据简化为 A区/B区/C区/D区，去掉「1F-」「示例图书馆 · 1层」「08:00—22:00」，`.zone-body` 改为 `flex-direction: row` + `space-between`，左侧区名、右侧「去预约」同行。

构建通过；node 测试 306/307（既有 `roles.test.js:115` 失败，与本改无关）。管理员端模板与样式规则未改动。
